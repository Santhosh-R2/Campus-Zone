# Smart Collage Mobile App

A professional Flutter application for student and faculty management.

## Prerequisites
- Flutter SDK installed
- Android Studio / VS Code with Flutter extension
- An active emulator or physical device

## Setup
1. Open the `mobile_app` folder in your terminal.
2. Run `flutter pub get` to install dependencies.
3. The app is configured to connect to: `https://collage-soon-backend.onrender.com`

## Running the app
```bash
flutter run
```

## Features
- **Register**: select your role and class teacher (for students).
- **Login**: automatic redirection to your specific dashboard.
- **Animations**: smooth entry animations on all screens.
- **Live tracking**: integrates with the backend bus location service.
